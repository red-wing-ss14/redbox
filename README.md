**redbox** это форк [Robust Toolbox](https://github.com/space-wizards/RobustToolbox), разрабатываемый командой Red Wing.

## Ссылки на проект

[Discord](https://discord.gg/VqpM7FfnHc)

## Документация/Вики

На [вики Space Station 14](https://docs.spacestation14.io/) представлена документация по игровому контенту SS14, движку, геймдизайну и многому другому.
Изменения движка, примененные командой Red Wing, будут вскоре опубликованы на отдельном ресурсе. Пока что все изменения движка доступны в нашем Discord.

## Участие в разработке

Разработка **redbox** ведется силами разработчиков команды Red Wing.
Если вы хотите помочь - вы должны являться разработчиком минимум одного сервера из сетки Red Wing.

## Сборка

Этот репозиторий содержит **движок** SS14. Это базовая платформа, на которой будут работать все серверы SS14. Поэтому сам по себе он не запускается: для работы ему необходим [репозиторий с игровым контентом](https://github.com/space-wizards/space-station-14).
